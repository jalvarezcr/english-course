Existence & Quantity

¿Qué hay en el refri?

Aprende a expresar existencia y cantidad en inglés.

El concepto de "Haber"

En español usamos una sola palabra mágica: "Hay". Decimos "Hay un coche" y "Hay dos coches".

En inglés, esto NO funciona así. Tienes que elegir entre Singular o Plural:

  • 1 There IS: Para uno solo (o cosas incontables como agua).
  • 2+ There ARE: Para dos o más cosas.

La Regla de Oro

Singular

There IS a car.

Plural

There ARE two cars.

Open the Fridge!

1 Apple

There is an apple

3 Lemons

There are three lemons

Water

There is some water

No cookies

There aren't any cookies

¿Contable o Incontable?

Liquidos y masas (Agua, Leche, Arroz): Siempre son singulares.
"There is water", "There is milk".

Negativos

Solo agrega "not" o usa la contracción.
"There isn't an apple", "There aren't any lemons".

Cuantificadores Básicos

A / An Singular

Para una sola cosa.

  • • There is a dog.
  • • There is an apple.
Some Afirmativo (Plural)

"Algunos" o "Algo de".

  • • There are some books.
  • • There is some milk.
Any Negativo / Pregunta

"Ningún" o "Nada de".

  • • There aren't any cars.
  • • Is there any water?

Estructuras Completas

Forma Singular (THERE IS) Plural (THERE ARE)
✅ Afirmativo There is a book. There are books.
❌ Negativo There isn't a book. There aren't books.
❓ Pregunta Is there a book? Are there books?
↩ Respuesta Sí Yes, there is. Yes, there are.
↩ Respuesta No No, there isn't. No, there aren't.

Contracciones útiles

There is → There's
There is not → There isn't
There are not → There aren't
There're (evítalo)

Cuantificadores Avanzados

Para hablar de cantidades específicas, usamos diferentes palabras según si es contable o incontable.

Para CONTABLES (plural)

MANY (muchos)

There are many people here.

A FEW (algunos / unos pocos)

There are a few students in the class.

FEW (pocos — sentido negativo)

There are few opportunities here.

Para INCONTABLES (singular)

MUCH (mucho)

There isn't much milk left.

A LITTLE (un poco)

There is a little sugar.

LITTLE (poco — sentido negativo)

There is little time.

A LOT OF / LOTS OF — ¡Funciona con TODO!

Significa "muchos/mucho" y se usa con contables E incontables. Es la forma más segura si no estás seguro.

Con contables:

There are a lot of cars.

There are lots of books.

Con incontables:

There is a lot of rice.

There is lots of coffee.

Resumen Rápido

Mucho/Muchos

Many (cont.)

Much (incont.)

A lot of (todo)

Algunos / Algo

A few (cont.)

A little (incont.)

Some (todo)

Pocos / Poco (negativo)

Few (cont.)

Little (incont.)

Any (negativo)

HOW MUCH vs HOW MANY

Para preguntar cantidades, usa la palabra correcta según contable / incontable.

HOW MANY (¿cuántos?)

Para contables plurales.

  • How many apples are there? → There are five.
  • How many students are in your class? → There are 30.
  • How many chairs are there? → There are six.

HOW MUCH (¿cuánto?)

Para incontables o para preguntar precio.

  • How much water is there? → There is a lot.
  • How much money do you have? → A little.
  • How much is this? → It's $20. (precio)

Describir Lugares con There is/are

Practica describiendo lo que hay en diferentes lugares cotidianos.

In my room

En mi habitación...

  • There is a bed. (cama)
  • There is a desk. (escritorio)
  • There is a lamp. (lámpara)
  • There are books. (libros)
  • There are posters. (afiches)

In the kitchen

En la cocina...

  • There is a fridge. (refri)
  • There is a stove. (estufa)
  • There is a sink. (fregadero)
  • There are plates. (platos)
  • There are glasses. (vasos)

In the city

En la ciudad...

  • There is a park. (parque)
  • There is a bank. (banco)
  • There is a hospital. (hospital)
  • There are schools. (escuelas)
  • There are restaurants. (restaurantes)

Texto modelo: "Mi vecindario"

In my neighborhood, there is a beautiful park. There are a lot of trees and there is a small lake. Near my house, there are two cafés and there is a supermarket. Unfortunately, there isn't a hospital, but there are some pharmacies. Are there many people on weekends? Yes, there are!
