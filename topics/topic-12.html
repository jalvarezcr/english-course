Causa y Efecto Real

El First Conditional (Primer Condicional) se usa para hablar de situaciones reales y posibles en el futuro. No es fantasía (eso es el segundo condicional).

Es la estructura favorita para hacer planes, amenazas ("Si no comes, no hay postre") y promesas ("Si apruebo, hago una fiesta").

El Efecto Dominó

IF It rains
WILL I will stay

Si la primera cae, la segunda sucede.

La Fórmula Matemática

IF
Present Simple (you study)
Future (Will) (you will pass)
!
El Error Mortal

Nunca pongas WILL junto a IF.
If I will go... If I go...

Situaciones Reales

Trabajo

If I get the job, I will buy a new car.

Si consigo el trabajo, compraré un auto nuevo.

Clima

If it is sunny tomorrow, we will go to the beach.

Si hace sol mañana, iremos a la playa.

Advertencia

If you don't study, you won't pass the exam.

Si no estudias, no aprobarás el examen.

Orden Inverso

She will be happy if you call her.

Ella estará feliz si la llamas. (Sin coma).
