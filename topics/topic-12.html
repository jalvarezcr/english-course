Causa y Efecto Real

El First Conditional (Primer Condicional) se usa para hablar de situaciones reales y posibles en el futuro. No es fantasía (eso es el segundo condicional).

Es la estructura favorita para hacer planes, amenazas ("Si no comes, no hay postre") y promesas ("Si apruebo, hago una fiesta").

El Efecto Dominó

IF It rains
WILL I will stay

Si la primera cae, la segunda sucede.

La Fórmula Matemática

IF
Present Simple (you study)
Future (Will) (you will pass)
!
El Error Mortal

Nunca pongas WILL junto a IF.
If I will go... If I go...

Situaciones Reales

Trabajo

If I get the job, I will buy a new car.

Si consigo el trabajo, compraré un auto nuevo.

Clima

If it is sunny tomorrow, we will go to the beach.

Si hace sol mañana, iremos a la playa.

Advertencia

If you don't study, you won't pass the exam.

Si no estudias, no aprobarás el examen.

Orden Inverso

She will be happy if you call her.

Ella estará feliz si la llamas. (Sin coma).

Los Tipos de Condicionales (Vista Rápida)

En inglés hay 4 tipos. Aquí nos enfocamos en el First Conditional (probable), pero conoce los demás:

Zero — Hechos universales

If + Present + Present

If you heat ice, it melts.

→ Si calientas hielo, se derrite (siempre).

★ First — Real y probable ★

If + Present + Will + Verb

If it rains, I will stay home.

→ Si llueve, me quedo. (Real)

Second — Hipotético / Imposible

If + Past + Would + Verb

If I had money, I would travel.

→ Si tuviera dinero, viajaría (no lo tengo).

Third — Pasado imposible (arrepentimiento)

If + Past Perfect + Would have

If I had studied, I would have passed.

→ Si hubiera estudiado, habría pasado.

Variaciones: Negativos y Preguntas

IF negativo (don't / doesn't)

  • If you don't hurry, you'll miss the bus.
  • If she doesn't call, I'll worry.
  • If we don't leave now, we'll be late.

Resultado negativo (won't)

  • If you don't study, you won't pass.
  • If it rains, we won't go out.
  • If I'm tired, I won't drive.

Preguntas con First Conditional

La pregunta va en la parte del WILL, no en el IF:

  • Will you come if I invite you? → ¿Vendrás si te invito?
  • What will she do if she misses the train?
  • Where will we go if it rains?

Alternativas al WILL en el Resultado

No siempre tienes que usar WILL. Puedes reemplazarlo con otros modales/verbos según el contexto:

CAN / MAY (posibilidad)

  • If you study, you can pass.
  • If we hurry, we may catch the bus.

SHOULD / MUST (consejo / obligación)

  • If you're sick, you should rest.
  • If it rains, we must take umbrellas.

GOING TO (plan)

  • If she calls, I am going to answer.
  • If they come, we are going to celebrate.

IMPERATIVO (instrucción)

  • If you see John, tell him to call me.
  • If it's hot, open the window.

Otras Conjunciones (Más allá de IF)

Para añadir variedad, hay otras palabras además de IF:

UNLESS (a menos que = if not)

I won't go unless you come with me.

= I won't go if you don't come.

WHEN (cuando = certeza)

When I get home, I'll call you.

Diferencia: IF (puede pasar) vs WHEN (seguro pasa).

AS SOON AS (en cuanto)

As soon as I finish, I'll let you know.

BEFORE / AFTER / UNTIL

I'll wait until you come.

After I eat, I'll study.
