Third Conditional: El Pasado Imposible

El Third Conditional habla de algo que NO pasó en el pasado y su consecuencia hipotética. Es el tiempo del arrepentimiento: "Si hubiera... habría...".

Es imposible cambiar el pasado, así que esta estructura siempre es teórica.

Fórmula

If + Past Perfect,

Subject + would have + participle

Estructura del Third Conditional

Condición (IF)

If + had + participle

If I had studied,

Resultado

would have + participle

I would have passed.

Significa: NO estudié → NO aprobé.

FormaEjemplo
✅ AfirmativoIf I had known, I would have helped.
❌ NegativoIf I hadn't been busy, I would have come.
❓ PreguntaWhat would you have done if you had failed?
📦 ContraccionesI'd have helped. / I wouldn't have gone.

Los 3 Usos del Third Conditional

1

Arrepentimientos

"If I had studied more, I would have passed."

→ Pero no estudié.

2

Crítica

"If you had listened, this wouldn't have happened."

3

Especulación pasada

"What would have happened if Hitler had won?"

Mixed Conditionals (Mezcla de tiempos)

Cuando la condición y el resultado están en tiempos distintos, mezclas Second y Third.

Tipo A: Condición PASADA → Resultado PRESENTE

If + Past Perfect, would + verb (presente)

  • If I had studied medicine, I would be a doctor now.
  • If she hadn't married him, she would be happier today.

→ Acción pasada que afecta el presente.

Tipo B: Condición PRESENTE → Resultado PASADO

If + Past Simple, would have + participle

  • If I were rich, I would have bought that house.
  • If he weren't shy, he would have spoken to her.

→ Característica permanente afecta evento pasado.

10 Ejemplos para Memorizar

1. If I had known you were sick, I would have visited.
2. She would have come if you had invited her.
3. If we hadn't missed the train, we would have arrived early.
4. I wouldn't have bought it if I had known the price.
5. If he had listened, he wouldn't have failed.
6. What would have happened if we had said no?
7. If they had left earlier, they would have caught the flight.
8. I would have called if I had had your number.
9. If you hadn't helped me, I wouldn't have finished.
10. She would have been happier if she had moved away.
